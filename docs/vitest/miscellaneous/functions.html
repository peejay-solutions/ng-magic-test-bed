Can be used to create a mock for an object that is an instance of a class.

Parameters :

An object that should implement partial of objectClass and contain all methods that you want to return something.

Your mocks methods will be overwritten with spies that call through to the mocks methods like your test framework's spyOn method. In addition to that a spy will be added for each additional method that was found on the objectClass' prototype.

src/mock/mock-interface.function.ts

mockInterface
mockInterface<I>(mock: Partial, dontSpy: unknown)
Type parameters :
  • I

Creates a mock object that satisfies the shape of a TypeScript interface I, without needing an NgMagicTestBed instance. Standalone alternative to magic.interfaceMock(). This does not (and cannot) replace I anywhere - interfaces have no runtime representation, so there is no prototype to reflect on the way mock() reflects on a class. Only the methods you actually provide in mock become spies - nothing can be auto-generated for members you omit, since there is nothing to reflect on for those either. mock only has to be a Partial, so omitted members are typed as present (I & SpyObj) but do not actually exist on the returned object - calling one you didn't provide throws at runtime despite compiling.

Parameters :
Name Type Optional Default value Description
mock Partial No

an object implementing whichever members of I you need for your test.
dontSpy unknown No false

optional parameter to prevent the default spy creation on the mock.
Returns : I & SpyObj

your mock, typed as I & SpyObj. Every method you provided is a spy that calls through to the implementation you supplied, like mock() does.

spyOnFunctionsOf
spyOnFunctionsOf(target: any, source?: any)
Parameters :
Name Type Optional Description
target any No

target's methods will be overwritten with spies. Inherited methods will be overwritten at target object and not on the prototype. This avoids unpleasant side effects.
source any Yes

this optional param can be used to create additional spies at the target object. For each method on source and its prototypes a spy will be created on the target.
