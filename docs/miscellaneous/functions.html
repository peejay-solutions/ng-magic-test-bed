spyOnFunctionsOf
spyOnFunctionsOf(target: any, source?: any)
Parameters :
Name Type Optional Description
target any No

target's methods will be overwritten with spies. Inherited methods will be overwritten at target object and not on the prototype. This avoids unpleasant side effects.
source any Yes

this optional param can be used to create additional spies at the target object. For each method on source and its prototypes a spy will be created on the target.

projects/ng-magic-test-bed/src/mock/mock.function.ts

mock
mock(spySource?, mock, dontSpy?: boolean)

Can be used to create a mock for an object that is an instance of a class.

Parameters :
Name Type Optional Description
spySource Yes
mock No

An object that should implement partial of objectClass and contain all methods that you want to return something.
dontSpy boolean Yes

optional parameter to prevent the default spy creation on the mock.
Returns : |

Your mocks methods will be overwritten with spies that call through to the mocks methods like your test framework's spyOn method. In addition to that a spy will be added for each additional method that was found on the objectClass' prototype.
