Public interfaceMock
interfaceMock<I>(mock: Partial, dontSpy: unknown)
Inherited from NgMagicTestBed
NgMagicTestBed:327
Type parameters :
  • I

Creates a mock object that satisfies the shape of a TypeScript interface I. This does not (and cannot) replace I anywhere - interfaces have no runtime representation, so there is no prototype to reflect on the way objectMock() reflects on a class. Only the methods you actually provide in mock become spies - nothing can be auto-generated for members you omit, since there is nothing to reflect on for those either. mock only has to be a Partial, so omitted members are typed as present (I & SpyObj) but do not actually exist on the returned object - calling one you didn't provide throws at runtime despite compiling. Use this instead of objectMock(undefined, mock) purely to avoid casting the result to I & SpyObj yourself. implementation you supplied, like objectMock() does.

Parameters :
Name Type Optional Default value Description
mock Partial<I> No

an object implementing whichever members of I you need for your test.
dontSpy unknown No false

optional parameter to prevent the default spy creation on the mock.
Returns : I & SpyObj

your mock, typed as I & SpyObj. Every method you provided is a spy that calls through to the implementation you supplied, like objectMock() does.
Public keptComponentImports
keptComponentImports(keptComponentImports: Array>)
Inherited from NgMagicTestBed
NgMagicTestBed:110

Declare that you want to keep several pipes/directives/standalone components exactly as they are, in one call. Each one is added to the imports (or declarations, for non-standalone classes) of your fixture component and all other kept components - the same effect as calling keptPipe() once per item, but without the per-item boilerplate and without querying for instances afterward. Typical use: keeping Angular's own structural directives/pipes (NgIf, NgFor, AsyncPipe, ...) that your fixture component's template relies on, since overriding a standalone component's imports for fixture/mock purposes replaces its imports array entirely - see keptDirectives()/keptComponents() if you also need access to the rendered instances afterward.
